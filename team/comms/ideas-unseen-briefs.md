# Ideas for unseen briefs, ranked (claude-prep, 2026-10-10). Nothing here is built yet unless marked done.

Already covered (checked): C/D/E/F/G/H variant briefs through the local sim, tool field names, renamed enums, memo overriding extract, Saturday holidays, day-first dates, coded outcomes, up to three products, dollar/euro/pound amounts in words, "2k"/"two grand" (done today).

1. **Auto-generated local scenarios from any spec** (free, high value). Today `local_sim.py` has hand-written scripts per known brief. A generic runner that derives scripts from the spec (pay in full, refuse, partial offer, hardship, wrong identity x limit, third party, tool failure) and asserts only brief-independent invariants (closes with an outcome/reason that exists in the tool API enums, no promise below the floor or past the deadline, notes only for products without a promise) would run inside `build.py` on every unseen brief and report real compiler gaps in the trace. Cost: model-free, about a day of work.
2. **Parse twice, diff the critical facts** (model calls only). Run extraction a second time and compare calendar, bands/floors, identity, outcome table, queues; re-ask only the differing sections. Cuts parser nondeterminism, the biggest unseen-brief risk. Cost: +2 to 3 parse calls (about 1 min).
3. **Enum guard at build time**: fail the build over to a repair prompt if the spec uses an outcome, reason, queue or note reason that the supplied tool API does not allow. Preflight already flags unmentioned values; make it blocking for the used ones.
4. **Spoken-text localisation**: the fixed engine phrases ("I did not catch that", "Thank you, goodbye") are English only. If `meta.language` is not English, translate the phrase table once with a model call at build time. Low probability (README speaks of other numbers and rules, not languages).
5. **Judge-aware wording check**: a cheap lint over generated agent lines for known judge triggers (mentioning "recorded" in the opening, naming the floor twice). Only useful with evidence from more transcripts.
6. **More identity schemes**: free-text fields (mother's maiden name, postcode with spaces, last-4 of card) matched fuzzily and spoken in pieces; check that postcode/alphanumeric answers survive the parts handling added in PR #4.
7. **Fallback when a brief has a rule the compiler cannot express**: today `extra_rules` go into the prompt. Add an end-of-call self-check pass that flags (in the trace only) any extra rule that touched an outcome.
